# MASFR ROS 2 Workspace

This workspace contains the ROS 2 software used to run and integrate MASFR flight, adhesion-sliding crawling, motion-capture feedback, visual-inertial sensor bridging, and multimodal mission execution.

The ROS 2 package names and executable names are preserved from the source code. The workspace directory was renamed from the uploaded project name to `masfr_ros2_ws` so that the repository layout reflects the MASFR control stack.

## Layout

- `src/` - ROS 2 packages and external PX4/VRPN dependencies.
- `build/`, `install/`, and `log/` - generated by `colcon build` and not required as source files.

## MASFR Packages

- [multimodal_motion](src/multimodal_motion/README.md) - mission coordinator for alternating flight and crawling segments, including `manipulation`, `node_crawling`, and `node_px4`.
- [robot_crawl](src/robot_crawl/Readme.md) - crawler teleoperation and motion-capture-based trajectory following. It sends serial packets to the STM32 crawling firmware under `../crawling/program_stm/`.
- [px4_offboard_control](src/px4_offboard_control/README.md) - PX4 offboard control examples and mission execution with optional serial coordination.
- [mocap_receiver](src/mocap_receiver/README.md) - TCP motion-capture receiver that republishes pose data to ROS 2 and PX4-compatible odometry topics.
- [sensor_to_vins](src/sensor_to_vins/README.md) - stereo image and PX4 IMU bridge for VINS-compatible topics.
- [launch_file](src/launch_file/README.md) - launch descriptions for starting the multimodal motion stack.

## External Packages

- [px4_msgs](src/px4_msgs/README.md) - PX4 uORB-equivalent ROS 2 message definitions.
- [px4_ros_com](src/px4_ros_com/README.md) - PX4 ROS 2 communication examples and frame conversion utilities.
- `px4-ros2-interface-lib/` - PX4 ROS 2 interface library and examples.
- [vrpn_client_ros](src/vrpn_client_ros/README.md) - ROS 2 VRPN client fork used when OptiTrack/VRPN pose streaming is required.

## Build

From the MASFR repository root:

```bash
cd "multimodal control/masfr_ros2_ws"
source /opt/ros/<ros2-distro>/setup.bash
colcon build --symlink-install
source install/setup.bash
```

Build a selected package during development:

```bash
colcon build --packages-select multimodal_motion
```

## Run Examples

```bash
ros2 run px4_offboard_control offboard_control
ros2 run robot_crawl crawl_from_rc
ros2 launch launch_file multimodal_motion.launch.py
```

See the package README files for exact topics, launch assumptions, and hardware requirements.

## Hardware And Configuration Notes

Several nodes contain machine-specific defaults that should be checked before hardware use:

- serial devices such as `/dev/ttyAMA1` and `/dev/ttyAMA2`;
- motion-capture host and port settings;
- CSV trajectory paths used by multimodal mission scripts;
- camera index and stereo frame dimensions used by `sensor_to_vins`.

Convert these values to ROS parameters or environment-specific launch arguments before using the workspace outside the original experiment setup.

## Safety

This workspace can command a PX4 aircraft and a crawling robot through serial links. Test in simulation or a restrained bench setup first, verify the serial device mapping, and keep an emergency stop path available before running motion nodes on hardware.
