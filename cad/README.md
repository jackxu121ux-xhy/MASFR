# CAD and Design Files

This directory contains releasable CAD, STL, and STEP geometry for the MASFR hardware.

## Contents

- `Crawling System/Crawling System Layout.STEP` - assembly-level crawling system layout.
- `DMS_sucker/DMS Sucker - Distributed micro spines.STL` - distributed micro-spine component for the DMS sucker.
- `DMS_sucker/DMS Sucker - Main body.STL` - main DMS sucker body.
- `DMS_sucker/DMS Sucker - Soft holder.STL` - soft holder component.
- `DMS_sucker/DMS Sucker - Soft Lips.STL` - soft lip component.
- `Leg_Module/Front Leg.STEP` - front leg module geometry.
- `Leg_Module/Hind Leg.STEP` - hind leg module geometry.

## Notes

File names are kept descriptive so that manuscript readers can identify the crawling layout, DMS sucker parts, and leg-module CAD without additional lookup tables. Check dimensions and manufacturing tolerances before using these files for fabrication.
